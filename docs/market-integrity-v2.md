# 第一階段資料完整性修復

## 行為變更

- 盤前報告只有帶有效 CRON_SECRET 的封存請求能產生，時段限台北時間 08:30（含）至 09:00（不含）。一般會員請求只讀取當日已封存且雜湊驗證通過的快照。
- 排程預定 08:45 執行；若 GitHub Actions 延遲至開盤後，拒絕補寫預測。快照不存在時明確顯示不可用，不改用盤後行情。
- 新快照保存完整輸入報價、參考交易日、資料可用性、風險因子、模型版本與 SHA-256。舊格式紀錄保留，但不納入新版統計；當日已封存內容不覆寫。
- 命中率統計最近 30／90 筆已驗證交易紀錄，排除未產生方向判斷、無效快照及未完成結果。資料不足不當成中性預測評分。
- 加權指數備援改用 TWSE 已驗證前收；全球市場共用具日期的前收計算。缺少連續日線時不產生漲跌百分比。
- 官方 TWSE 交易日期與年度休市表無法確認時，盤前封存停止。技術分析及動能回測只讀取參考交易日以前的已完成日線。
- 融資優先讀取 TWSE MI_MARGN；明確將仟元轉億元，融券保留張。第三方備援必須符合參考交易日。未知欄位或單位拒絕解析。
- TAIFEX 按 ContractCode、Item、Date 及 OpenInterest(Net) 選取外資台指期淨口數，不讀取契約金額欄位。P/C 百分比以原始賣權／買權口數交叉計算。
- 夜盤先查授權主來源、授權備援，最後才採公開網頁。公開來源標示月份未驗證／降級，並限制報價年齡；休市表無法確認時不使用公開來源。授權 feed 仍須自行依 TAIFEX 交易日、合約與時段提供正確資料；不將現貨休市表視為期交所完整交易日曆。
- 產業輪動要求快照與歷史日對齊；揭露觀察成分股涵蓋率，含未取得上櫃歷史的族群降級，不以缺漏資料產生已驗證輪動訊號。成交金額變化不命名為淨資金流。
- 法人資料須符合已確認交易日期；未標日期的大盤網頁表格不再直接傳給前台。
- 前端失敗時移除失效資料；夜盤報價超過兩分鐘停止顯示為有效價，年齡依時間動態計算。總結不參與獨立訊號計票，缺值另列待確認。
- 來源健康檢查加入必要數值欄位、日期、融資單位與 P/C 口數驗證；CI 執行資料回歸測試。

## 上線前驗收

本 PR 不部署或合併 main。合併／部署須另由維護者安排。

1. 在預覽環境核對未登入 401、會員讀取固定快照、無快照 503，以及非 cron 產生請求 403。
2. 在盤前時段確認排程憑證可用，封存到新版本後核對頁面與快照方向完全一致；逾時請求必須 409，不能手動補造當日預測。
3. 檢查休市表年度覆蓋、前一交易日與跨月資料；休市或無法確認時停止封存。
4. 使用固定合成樣本模擬來源過期、回傳缺值、主來源失敗和全部失敗，不把測試資料寫入正式資料集。
5. 在桌機及手機檢查夜盤更新失敗與過期狀態、盤前八項分析加總、缺值與來源日期。
6. 對照當日官方資料檢查融資換算、期貨淨口數、P/C 及產業成分股覆蓋率；此為部署前人工驗收，不以單次連通成功替代。
7. 確認新格式封存後才累積命中率。舊紀錄不遷移為已驗證預測。

## 績效界線與後續資料

動能模型的樣本外績效與九項風險限縮後的最終建議為不同結果。程式明確標示前者僅為基礎模型績效，沒有宣稱最終建議的策略報酬。

新快照已保存每日最終建議倉位，可供後續依實際可執行價格、交易成本及模型版本計算策略績效。尚未接入可驗證的執行成交資料，因此不補造最終策略歷史績效，也不宣稱風險權重已完成校準。

公開資料來源可能改版、延遲或停止供應；程式會拒絕未知格式，不能保證每個交易日均能產生完整分析。SHA-256 用來核對內容一致性，並非數位簽章。
